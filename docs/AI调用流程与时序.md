# 词灵AI 调用标准流程与四个功能时序说明

> 可直接粘贴进课程设计报告。

## 一、词灵AI 调用标准流程

所有词灵AI 调用统一经过下述标准链路，无论是「就地调用（模式A）」还是「对话归集（模式B）」。

```
┌────────┐   ┌──────────┐   ┌────────────┐   ┌────────────┐   ┌─────────┐   ┌──────┐
│ 登录校验 │ → │ 额度校验  │ → │  全局缓存   │ → │  RAG 检索   │ → │ 调用千问 │ → │JSON清洗│
└────────┘   └──────────┘   └────────────┘   └────────────┘   └─────────┘   └──────┘
     │            │               │                 │              │             │
  拦截器完成    AiQuotaService  Redis 命中直接返回  Qdrant 查询   超时/重试/   严格解析
  鉴权+UserId   每日10次/用户   省token+加速       top4知识点    降级处理     失败即格式异常
```

### 各环节说明

1. **登录校验**：由 `AuthInterceptor` 统一完成，校验 `Authorization: Bearer <token>`，
   校验通过后将 userId 写入 `UserContext`（ThreadLocal）。
2. **额度校验**：`AiQuotaService.checkAndConsume(userId)` 基于 Redis 计数
   `ai:quota:{userId}:{yyyyMMdd}`，当日首次计数时设置 TTL（2天），实现每日自动重置；
   超限自动回滚计数并抛出"今日额度已用完"友好异常。数据库仅 `@Async` 异步统计
   `ai_used_today / ai_used_total`，**业务流程绝不依赖数据库查额度**。
3. **全局缓存**：`AiService` 以 `md5(system + user)` 为 key 查询 Redis `ai:cache:*`
   （TTL 24小时），命中则直接返回 JSON，不再调用大模型，节省 token、加快响应。
   阅读解析另有 MySQL 表 `ai_word_explain` 做持久化缓存（按 `user_id + content_hash` 唯一）。
4. **RAG 检索**：`RagSearchService` 用千问 `text-embedding-v3` 将问题编码为向量，
   到云端 Qdrant 集合 `ling-word-kb` 做相似度检索，取 top4 知识点文本注入提示词
   `{rag_context}`。RAG 不可用（未配置/超时）时返回空列表，仅凭模型通用知识作答，优雅降级。
5. **调用通义千问**：`AiService` 通过 Spring AI `ChatModel`（OpenAI 兼容协议）调用
   `qwen-flash`（免费/省token）；以 `CompletableFuture.get(timeout)` 实现硬超时（默认 45s），
   按 `retry-times` 自动重试；`ai.enable=false` 时容器无 ChatModel Bean，
   直接抛出"词灵AI暂时不可用"友好异常，**其余学习功能不受影响**。
6. **JSON 清洗**：去除 ```` ```json ```` 围栏、只保留 `{...}` 片段，再用 Hutool JSON
   **严格解析**；解析失败抛出格式异常，由 `GlobalAiExceptionHandler` 统一转成友好提示，
   绝不暴露堆栈。

### 限流与降级

- 系统级 QPS 限流：`ai:sys:sec:{秒}` 计数器，超过 20 次/秒触发限流；
- 用户级冷却：`ai:cool:{userId}` 3 秒内不允许重复调用；
- 三层降级：额度不足 → 提示明天再来；AI 异常/超时 → 提示"词灵AI暂时不可用"；
  格式异常 → 提示重新生成。任何情况下背单词、复习、试卷、游戏、统计均正常运行。

## 二、四个 AI 功能的时序说明

### 1. 阅读助手（模式A · 就地调用）

```
用户                    前端阅读助手页                    后端 WordExplainAiController        AiService          大模型
 │  粘贴英文段落并点"解析"  │                                │                                 │                  │
 │───────────────────────→│  POST /api/ai/explain          │                                 │                  │
 │                        │───────────────────────────────→│  md5(text) 查 ai_word_explain    │                  │
 │                        │                                │──缓存命中──────────────────────→│                  │
 │                        │                                │←───────────────直接返回JSON──────│                  │
 │                        │                                │  未命中：额度→限流→Redis缓存→     │                  │
 │                        │                                │────────────────────────────────→│  ChatModel 调用  │
 │                        │                                │←───────── 清洗后的结构化JSON ─────│←────────────────│
 │                        │←──────── 渲染JSON(高亮生词) ────│  写入 ai_word_explain 持久化      │                  │
 │  弹窗展示解析卡片        │                                │                                 │                  │
 │  点击"加入生词本"        │→ POST /api/word-book/batch-add │                                 │                  │
```

特点：不进入对话历史、不跳转AI页面；完整权限、额度、缓存、降级。

### 2. 生词巩固（模式B · 对话归集）

```
用户            生词本页                词灵AI对话页(/ai-assistant)     后端 LingAiAssistant       AiService          大模型
 │  勾选单词点"巩固"  │                                                                          │                  │
 │──────────────────→│ 携带 mode=word_review&payload=单词JSON&title 跳转                            │                  │
 │                   │ 读取URL参数，顶部来源提示条，输入框预填内容                                    │                  │
 │  点击发送          │─────────────────────── POST /api/ai/chat/send ──→ 额度→限流→缓存→RAG───────→│                  │
 │                   │←──────────── JSON(卡片结构)存入消息并返回渲染 ────│                          │  ChatModel 调用  │
 │  多轮追加要求      │─────────────────────── 再次发送(同上链路) ────────│                          │                  │
 │  点击"保存这份助记内容" │── POST /api/review/save {jsonData} ──→ 后端严格Schema校验,非法拒绝      │                  │
 │                   │←────────── 保存成功,生词本页可回看巩固包 ──────────│                         │                  │
```

渲染层：`AiRenderUtil` 把 JSON `word_list` 渲染成美观的单词卡片（音标/释义/助记/
易混提醒/例句/巩固小题），答案解析默认折叠；解析失败兜底为干净纯文本。

### 3. AI 生成试卷（模式B · 对话归集）

```
用户          AI试卷生成页(选择单词池/题量/难度/题型侧重)        词灵AI对话页             后端 ExerciseService        AiService
 │  配置偏好点"生成"   │                                        │                          │                        │
 │───────────────────→│ 携带 mode=paper&payload=单词池&custom=要求 跳转                       │                        │
 │                    │ 预填内容,可多次调整难度/题量/题型比例                                   │                        │
 │  点击发送           │──────────────────────── POST /api/ai/chat/send ────────────────────→│  额度→限流→缓存→调用    │
 │                    │←─────────── JSON(question_list 结构)渲染成预览版试卷 ────────────────│←──────────────────────│
 │  满意点"导入为本套练习试卷"│── POST /api/paper/import {jsonData} ──→ 严格校验5种题型/题量/选项/答案 │                        │
 │                    │←──────────── 导入成功,进入做题页 ────────────────────────────────────│                        │
 │  作答并交卷         │──────────────────────── POST /api/paper/submit ────────────────────→│  Java后端判分/计分/回写 │
 │                    │←──────────── 得分/批改/解析,错题自动收录 ────────────────────────────│                        │
```

仅允许 5 种题型：`en2cn`、`cn2en`、`spell_fill`、`context_choice`、`match`。
判分全部由 Java 后端完成（单选题精确匹配、拼写忽略大小写、匹配题 JSON 数组逐项比对）。

### 4. 自由英语答疑（模式B · 严格限制无关内容）

```
用户          词灵AI对话页(直接进入)                后端 LingAiAssistant      RagSearchService      AiService          大模型
 │  提问        │                                    │                        │                     │                  │
 │─────────────→│  POST /api/ai/chat/send(mode=chat)│                        │                     │                  │
 │              │──────────────────────────────────→│  额度→限流→缓存未命中    │                     │                  │
 │              │                                    │──问题编码embedding──→│  Qdrant top4         │                  │
 │              │                                    │←────────知识点文本─────│                     │                  │
 │              │                                    │─────────────────────────────────────────────→│  ChatModel 调用  │
 │              │←──── JSON {type,title,content,tips} 或 refuse 拒绝JSON 渲染成富文本 ───────────────│←────────────────│
 │  点击右上角⭐  │── POST /api/ai/favorite ──────────→│  存入 ai_favorite(我的AI笔记)                │                  │
```

- 提示词 `AI_CHAT_SYSTEM` 硬性限定回答范围仅为英语学习内容；
  非英语学习话题直接返回 `{"type":"refuse",...}` 礼貌拒绝，不展开不提供信息。
- 支持多轮上下文：后端自动携带最近 6 条历史消息。
- 每条 AI 消息右上角收藏 ⭐，收藏内容在"我的AI笔记"页面查看。
